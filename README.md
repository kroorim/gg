Minimal starter project — a small Flask API to build on.

## What's here

- `app/main.py` — Flask app with a couple of working routes (`/`, `/health`, `/api/hello`)
- `tests/test_main.py` — basic tests for those routes
- `requirements.txt` — dependencies

## Getting started

```bash
pip install -r requirements.txt
python app/main.py
```

Then open http://localhost:5000/

Run tests:

```bash
pytest
```
